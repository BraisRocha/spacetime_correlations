# Source catalogues

This folder holds the source catalogues used to place flares in the targeted
search (see `scripts/montecarlo/run_targeted_search.py`).

**The catalogue files are private and are not tracked in git.** Only this
README and a `.gitkeep` placeholder are committed, so the folder structure
exists on a fresh clone while the data themselves stay local. After cloning,
drop the files into this directory before running the targeted search.
